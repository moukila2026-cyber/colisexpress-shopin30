Questions fréquentes

Les réponses aux questions les plus courantes. Pour toute autre demande, écrivez-nous sur WhatsApp.

Comment obtenir le code de suivi de mon colis ?

L'agence expéditrice génère un code unique au format CLI-XXXXXX lors de l'enregistrement. Il figure sur le reçu, avec un QR code qui ouvre directement le suivi.

Quelles sont les étapes de mon colis ?

Enregistré, Expédié, En transit, Arrivé à l'agence de destination, puis Retiré. Chaque étape est horodatée dans l'historique visible sur le suivi.

Mes informations personnelles sont-elles visibles ?

Non. Le suivi public n'affiche ni nom, ni téléphone, ni numéro de pièce d'identité. Ces informations ne sont accessibles qu'aux agences concernées par le colis.

Que dois-je apporter pour retirer mon colis ?

Votre pièce d'identité (CNI) et votre code de suivi. L'agence enregistre le retrait avec le nom et le numéro de la pièce présentée.

Combien coûte l'envoi ?

Le prix est fixé par l'agence expéditrice au moment de l'enregistrement, en FCFA, selon la destination et le poids du colis. Utilisez notre estimateur de devis ci-dessus pour connaître le prix depuis les grilles des agences actives, puis contactez l'agence sur WhatsApp.

Comment rejoindre le réseau COLIS EXPRESS ?

Créez un compte d'agence en quelques minutes. Pour envoyer un colis vers une autre ville, il faut qu'une agence de destination soit inscrite dans le réseau.

J'ai oublié mon mot de passe agence.

Sur la page de connexion, cliquez sur « Mot de passe oublié ? ». Un lien de réinitialisation vous est envoyé par e-mail.

Votre agence est prête à expédier ?

Créez votre espace agence pour enregistrer vos colis et rejoindre le réseau COLIS EXPRESS.
